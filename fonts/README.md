# Fonts

`noto-sans-tc.js` holds **Noto Sans TC** (the variable font
`NotoSansTC-VF.ttf`, unmodified), gzipped and base64-encoded by
`tools/build_font.py`. The PDF export embeds the parts of it that each report
uses, so English, German and Traditional Chinese text is real, searchable text
in the PDF.
